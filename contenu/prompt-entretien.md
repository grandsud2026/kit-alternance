# Prompts IA pour préparer un entretien

Copie un prompt avec le bouton « Copier », colle-le dans ton assistant IA, puis remplace tout ce qui est entre [CROCHETS].

## Prompt 1 : préparer les questions clés

```
Je me prépare pour un entretien d'alternance chez [NOM ENTREPRISE],
poste [TITRE DU POSTE].

Voici l'offre :
[COPIER L'OFFRE]

Quelles sont les 15 questions les plus probables qu'on va me poser ?
Pour chaque question :
1. Explique pourquoi ils la posent (qu'est-ce qu'ils cherchent ?)
2. Donne-moi une structure de réponse idéale
3. Donne-moi 2 ou 3 exemples concrets tirés de mon profil

Mon profil pour adapter les réponses :
[RÉSUMÉ DE VOTRE PARCOURS]

Prépare-moi comme un coach d'entretien.
```

## Prompt 2 : ton pitch en 30 secondes

```
Imagine que je croise le responsable du recrutement de [NOM ENTREPRISE]
dans un ascenseur. Je dois lui présenter mon profil en 30 secondes.

Mon contexte :
- Formation : [VOTRE FORMATION]
- Expériences : [VOS EXPÉRIENCES CLÉS]
- Points forts : [VOS ATOUTS]
- Motivation : [POURQUOI CETTE ENTREPRISE ?]

Le poste visé : [TITRE]

Crée-moi un pitch qui :
1. Capte l'attention en 5 secondes
2. Montre rapidement que mon profil correspond au poste
3. Se termine par une question qui relance la conversation
4. Reste naturel et pas trop « commercial »
5. Peut se dire sans notes

Donne-moi 2 versions : une classique, une plus créative.
```

## Prompt 3 : les questions à poser au recruteur

```
Entretien d'alternance chez [NOM ENTREPRISE] pour le poste de [TITRE DU POSTE].

Ce que j'ai découvert sur l'entreprise :
[QUELQUES INFOS SUR L'ENTREPRISE]

Ce que j'aimerais savoir :
[VOS VRAIES QUESTIONS]

Crée-moi une liste de 5 à 7 questions que JE devrais poser en entretien
pour :
1. Montrer que je me suis renseigné et que je suis intéressé
2. Comprendre si le poste me correspond vraiment
3. Montrer mon sérieux et ma curiosité
4. Créer une vraie conversation (pas un interrogatoire)

Les questions doivent être pertinentes, pas génériques.
```

## Prompt 4 : parler d'une expérience difficile

```
Dans mon CV ou mon parcours, il y a une expérience délicate :
[DÉCRIRE LA SITUATION : changement d'école, période sans activité,
mauvaise expérience, etc.]

Comment en parler en entretien pour :
1. Être honnête et authentique
2. Montrer ce que j'en ai appris
3. Ne pas faire fuir le recruteur
4. En faire un point fort (« comment ça m'a fait grandir »)
5. Être concis (30 secondes maximum)

Donne-moi plusieurs façons de formuler cette réponse selon le ton
du recruteur.
```
