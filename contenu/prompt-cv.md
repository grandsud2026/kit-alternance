# Prompts IA pour améliorer ton CV

Copie un prompt avec le bouton « Copier », colle-le dans ChatGPT, Claude, Gemini ou Copilot, puis remplace tout ce qui est entre [CROCHETS].

## Prompt 1 : adapter ton CV à une offre

```
Mettez-vous à la place de [NOM ENTREPRISE] qui recrute pour le poste de
[TITRE DU POSTE D'ALTERNANCE], et vous souhaitez recruter
le candidat PARFAIT pour répondre à vos besoins.

Voici notre offre d'alternance :
[COPIER-COLLER L'OFFRE COMPLÈTE]

Voici mon CV actuel :
[COPIER-COLLER VOTRE CV]

Analysez-le et proposez-moi des modifications précises pour :
1. Utiliser le même vocabulaire que l'offre
2. Mettre en avant les compétences qu'ils cherchent
3. Restructurer mes expériences pour répondre à leur besoin
4. Ajouter des mots-clés pertinents
5. Améliorer le format pour plus de lisibilité

Soyez très précis dans vos changements et justifiez chaque modification.
```

## Prompt 2 : adapter ton CV aux valeurs de l'entreprise

```
Je recherche une alternance chez [NOM ENTREPRISE].
Voici ce qu'ils valorisent (d'après mes recherches) :
- [VALEUR 1]
- [VALEUR 2]
- [VALEUR 3]
- [CULTURE D'ENTREPRISE]

Mon CV actuel :
[COPIER-COLLER VOTRE CV]

Comment puis-je restructurer mon CV pour montrer que j'incarne ces valeurs ?
Quelles expériences et compétences dois-je mettre en avant ?
Quel langage dois-je utiliser pour correspondre à leur culture ?

Propose-moi une version révisée avec des explications.
```

## Prompt 3 : hiérarchiser les éléments du CV

```
Je candidate à une alternance chez [NOM ENTREPRISE] pour le poste
de [TITRE DU POSTE].

Les éléments clés de l'offre :
[COPIER JUSTE LES ÉLÉMENTS CLÉS DE L'OFFRE]

Mon CV contient :
[LISTER VOS EXPÉRIENCES, COMPÉTENCES ET FORMATIONS]

Dans quel ordre dois-je les présenter ? Qu'est-ce que je dois :
- mettre en AVANT (en premier)
- mettre en ÉVIDENCE (section dédiée)
- mentionner rapidement
- ENLEVER ou MINIMISER

Justifie pour chaque point pourquoi cette hiérarchie est meilleure.
```

## Prompt 4 : reformuler les titres de tes expériences

```
Je candidate chez [NOM ENTREPRISE] pour le poste de [TITRE DU POSTE].

Mes expériences ont actuellement ces titres :
- [TITRE EXPÉRIENCE 1]
- [TITRE EXPÉRIENCE 2]
- [TITRE EXPÉRIENCE 3]

Ce que l'entreprise recherche (d'après l'offre) :
[COPIER LES COMPÉTENCES CLÉS DE L'OFFRE]

Comment pourrais-je reformuler mes titres d'expériences pour montrer
que j'ai directement ce qu'ils cherchent ?

Donne-moi plusieurs options pour chaque titre, en commençant par celle
qui correspond le mieux à l'offre.
```

## Prompt 5 : réécrire la description d'une expérience

```
Poste visé : [TITRE DU POSTE] chez [NOM ENTREPRISE]

Une de mes expériences :
Titre : [TITRE EXPÉRIENCE]
Description actuelle : [VOTRE DESCRIPTION ACTUELLE]
Résultats et apprentissages : [CE QUE VOUS AVEZ APPRIS OU RÉALISÉ]

Ce que l'entreprise valorise (d'après l'offre) :
[ÉLÉMENTS CLÉS DE L'OFFRE]

Réécris la description de mon expérience pour :
1. Utiliser le même vocabulaire que l'offre
2. Mettre l'accent sur les résultats (pas seulement les tâches)
3. Montrer comment cette expérience m'a préparé à CE POSTE
4. Être concis (2 à 3 lignes maximum)
5. Inclure des chiffres si possible

Donne-moi 2 ou 3 versions, de la plus classique à la plus percutante.
```
